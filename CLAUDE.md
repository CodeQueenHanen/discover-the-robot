# Claude Guidelines — Discover the Robot

## How to work with me on this project

I am a junior/mid developer learning cloud and backend concepts for the first time.

Coming from a management background, I understand systems thinking but need help

with syntax, tooling, and cloud-specific concepts.

## Azure CLI Rules

- Always explain every `az` command before I run it

- Break down what each flag does and why it's needed

- Tell me what the command will create, change, or delete

- Warn me explicitly if a command is destructive or irreversible

- Never include `--yes` or `-y` on destructive commands without calling it out

- If a command could cost money, tell me approximately how much

## General Coding Rules

- Explain what you're doing and why before showing code

- Prefer simple and readable over clever

- Point out when there's a tradeoff and explain both sides

- If I'm about to do something risky, stop and tell me first

- Always tell me what to do next after completing a step

## Stack Reminders

- Frontend: vanilla HTML + JavaScript (no frameworks)

- Backend: Azure Functions v4, Node.js 18

- Database: Azure Table Storage via @azure/data-tables SDK

- Deployment: GitHub Pages (frontend), Azure Function App (backend)
